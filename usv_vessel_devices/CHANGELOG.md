# Changelog

## Unreleased

### Fixed

- 补充 `usv_bringup system.launch.py` 实际使用的 CCS 场景启用配置和说明，避免仅修改仿真包默认配置导致整机入口没有模型附件及设备服务。

### Added

- CUSTOM 双舷外机可选起翘：真实横向铰链、限速速度驱动、左右独立/同时 topic 与服务、独立状态，保留原推力和转向接口；起翘断推，落回后不回放旧推力。整机 bringup CCS 场景启用，其他配置默认关闭。
- 起翘配置/模型兼容回归及使用真实 bringup 船模的隔离物理联调，覆盖联锁、原生推力、转向、暂停/重置与双船生命周期。
- 保留十二个桅杆灯，另增船顶四角 `roof_*` 红绿灯，独立控制且不随桅杆运动/缩放；默认十六灯，旧状态数组前缀不变，可用 `roof_lights_enabled` 关闭，旧船顶回退模式不重复叠加。
- 替换剩余七套原灯为独立红绿灯，默认共十二灯（含顶部白灯）；中线分层红绿交替，支持逐灯颜色配置，保留原五灯状态前缀与接口。
- 桅杆默认整体 XYZ 放大两倍至 1.195738 m，包含底座、横杆、灯具及安装坐标，不移动船上安装基准或现有传感器。
- 四盏红绿灯默认改挂活动桅杆的两层横杆，顶部白灯保留，五灯共同随动；保留原 front/rear ROS 名称并对应上/下层。
- 删除两层横杆原四套装饰灯的几何，提取托盘安装基准；位置和适配后的灯具尺寸随桅杆等比例缩放，可配置回退船顶布局。
- 默认使用用户提供 STEP 转换的桅杆和闭盖航行灯，网格已转换为米制并记录来源哈希；CAD 工具仅用于离线转换。
- 桅杆拆分为固定底座、活动杆体和顶部受控灯罩；四角灯拆分外壳和灯罩，保留五灯 ROS 接口。
- CAD 原尺寸/等比例缩放参数及简化模型回退，增加网格完整性、单位、材质隔离和固定底座测试。
- 同包提供灯与可放倒桅杆的插件、模型、ROS topic/service 和状态消息。
- 左前/左后红灯、右前/右后绿灯、随桅杆运动的白灯，分别独立控制。
- 真实关节反馈、目标校验、限速、暂停时服务响应和重置处理。
- 独立测试台、观察相机、模型转换和控制器测试。
