# PX4 CGO3 Meshes

The four STL files in `meshes/` are copied from PX4-Autopilot's
`Tools/simulation/gz/models/gimbal/meshes/` directory. They are used only as
visual assets by the ROS-controlled WAM-V payload gimbal; its model, ROS
interfaces, and control implementation remain in `usv_sim_full`.

Source project: PX4-Autopilot, BSD-3-Clause license.
