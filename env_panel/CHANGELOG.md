# Changelog

后续修改本包功能、配置或文档时，应在 `Unreleased` 中记录面向使用者的变更。

## Unreleased

### Added

- 新增功能包架构和数据流文档。
- 新增 `env_panel/RadarPanel`，在 RViz 中提供完整雷达参数与服务控制。
- 新增 `env_panel/UsvViewPanel`，提供一次性远景预设和本船跟随视角快捷切换。
- 新增视角控制面板技术说明，记录视角逻辑、参数调节、编译和故障排查方法。

### Changed

- 更新 README，说明 RViz 面板加载方式。
- 优化雷达面板在大字体和高 DPI 下的布局，合并回波调节项并固定底部操作按钮。
- 全局俯视改为点击时以本船当前位置为中心定位，定位后保持非跟随模式。
- 移除与斜后跟随功能重叠、展示效果不佳的自由环绕入口。
