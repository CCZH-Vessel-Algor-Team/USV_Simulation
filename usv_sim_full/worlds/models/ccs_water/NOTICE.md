# CCS water visual resources

The GLSL programs are local adaptations of the bundled VRX `coast_waves`
programs (Apache-2.0). Original notices for the UUV Simulator Authors (2016)
and Rhys Mainwaring (2019) are retained in the shader sources. Changes made
2026-11-11 restore the existing normal-map and environment-map shading, and
optionally advect the normal-map UVs using the existing world current topic.

`materials/textures/wave_normals.dds` and `skybox_lowres.dds` are unmodified
copies from `vrx/vrx_gz/models/coast_waves/materials/textures`. They are kept
locally because the existing `vrx::WaveVisual` plugin resolves those fixed
filenames relative to the water model. See the accompanying Apache-2.0
license and the VRX distribution's notices.

`meshes/ccs_water.dae` is generated by `usv_sim_full/tools/generate_ccs_water_mesh.py`.
It uses 3 m spacing in the CCS spawn area, 6 m nearby, and coarser rings offshore
in one 36 km surface. To avoid undersampling, the vertex shader fades wave
components as the rings become coarser. It boosts gentle crests and troughs for
display only, without changing the wavefield shared with physics or the current
advection. No code or assets from the GPL `asv_wave_sim` repository are incorporated,
and no FFT/CGAL dependency is added.
