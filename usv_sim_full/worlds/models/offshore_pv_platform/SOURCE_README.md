# 固定桩式海上光伏平台 · Gazebo Sim

`offshore_pv_platform/` 是一个可重复实例化的 Gazebo 模型，包含 SDFormat 1.9、网格和双面组件贴图。模型是静态刚体，桩、主要桁架杆件和组件板带带有碰撞体，可用于平台周边和板下的航行、避障与传感器仿真。上部组件均按真实米制尺寸建模。

## 插入现有世界

把整个 `offshore_pv_platform/` 目录放进项目的模型目录，例如 `/path/to/project/models/`。启动 Gazebo 前，把包含 `offshore_pv_platform/` 的目录加入搜索路径：

```sh
export GZ_SIM_RESOURCE_PATH="/path/to/project/models${GZ_SIM_RESOURCE_PATH:+:$GZ_SIM_RESOURCE_PATH}"
```

将下面的片段放在你的 SDF 文件的 `<world>` 内：

```xml
<include>
  <uri>model://offshore_pv_platform</uri>
  <name>offshore_pv_01</name>
  <pose>0 0 0 0 0 0</pose>
</include>
```

`pose` 的前 3 项是平移（米），后 3 项是滚转、俯仰、偏航（弧度）。模型原点位于平台中心的设计水线处。如果你的世界水面为 `z = 0`，第三项设为 `0`。如果水面标高不同，将第三项设为该标高。组件沿 X 方向成行，沿 +Y 方向升高，受光面朝 −Y。复制 `<include>` 并修改 `name` 与 `pose` 可排列多台平台，例如用 70 m 的 X 向中心间距或 47 m 的 Y 向中心间距。

## 模型尺寸

| 项目 | 尺寸 |
| --- | --- |
| 单台外包络（水平投影） | 约 60.0 × 35.0 m |
| 单块组件（长 × 宽 × 边框厚） | 2.278 × 1.134 × 0.035 m |
| 安装倾角 | 15° |
| 光伏组件排布 | 6 条板带，每条 2 排 × 52 块，共 624 块 |
| 钢管桩 | 4 根，桩身外径 1.00 m，中心坐标为 `(±18, ±10.5)` m |
| 桩身上下标高 | −24.00 m 至 +5.04 m |
| 主桁架下缘 | +4.96 m，桩顶节点的承托板最低点约 +4.94 m |
| 组件边框最低 / 最高点 | 约 +6.63 / +7.85 m |

照片提供了固定桩、架空网架和成排组件的外观参考。平台的约 60 × 35 m 外形、四桩、15° 倾角参考公开的山东垦利 HG14 工程，组件尺寸参考隆基 Hi-MO 5 双玻组件规格。桩距、桩径、各标高及杆件布置采用仿真假设。照片中的具体项目尺寸需以实测或工程图为准。[中建八一 HG14 工程资料](https://www.cscec81.com/199.news.detail.phtml?news_id=9095) · [隆基 Hi-MO 5 产品规格](https://static.longi.com/Hi_MO_5_Product_brochure_EN_2022_05_9e90029efe.pdf)

板面碰撞由每条板带中的两条窄盒组成，保留板带之间和两排之间的缝隙，沿 X 方向相邻组件之间的 20 mm 缝隙按连续面处理。次檩、支撑小件和接线盒作为视觉几何。模型包的范围是刚性结构与碰撞，海面、水动力、结构变形和发电计算由仿真世界或独立插件提供。
