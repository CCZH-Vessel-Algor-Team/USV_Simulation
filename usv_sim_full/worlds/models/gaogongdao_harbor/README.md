按用户卫星截图解释码头设施，使用当前 CCS 海图 `chart_obstacle_001` 的已有几何作为码头平面边界。大桥已按用户要求删除，包括桥面、桥墩、护栏、标线与碰撞体。

## 已完成

- 折线形防波堤、码头面、防浪墙、外侧护坡块石。
- 简化仓库、蓝色屋顶、车辆、堆放物、系缆桩、三处支栈桥和停泊小船。
- Gazebo Harmonic 静态模型、Blender 源文件、CCS 预览世界及当前第二套环境的插入脚本。

## 尺度与估算

1 Blender 单位 = 1 米。码头面顶标高暂取相对仿真水面 +3.2 m，防浪墙高度 1.1 m，仓库高度约 2.7～3.4 m。所有高度为本轮估算，不代表实测海拔、潮位基准或工程设计标高。

截图无地理参考和比例尺，因此设施位置采用人工解释；码头面轮廓直接截取既有海图的 x[-262,-80]、y[145,435] m 区域，不用截图重新推算海岸线。现有海图本身的栅格化误差仍然保留。仓库、船只、栈桥数量与位置属于近似外观，尚未逐一测绘。

## 碰撞与性能

- 原海图保留水陆边界碰撞。
- 新增码头顶面碰撞和 11 个建筑/防浪墙简单碰撞盒。
- 护坡块石、栈桥、停泊小船仅为静态视觉设施，不具有浮力或运动控制。
- 导出可视网格约 5,001 个三角面；单个网格，三张 64×64 材质图集。

## 文件与接入

- `gaogongdao_harbor.blend`：源文件；`HARBOUR` 集合为主体，其余为预览海面、灯光与相机。
- `models/gaogongdao_local_harbor_v1`：Gazebo 模型；模型自身坐标为局部坐标，使用时需放到 ENU `-170 270 0`。
- `construction-manifest.json`：估算值、原点、范围与碰撞配置。
- `worlds/ccs_open_water_gaogongdao_preview.sdf`：原 CCS 世界的附加版本，需配合原项目的波浪、海图等资源。
- `insert-agent2.sh`：往已有第二套 CCS 世界插入模型；当前已经插入，不要重复执行。返回 Boolean 只代表请求被接收，仍需查看场景清单。
- `harbor-preview.png`、`harbor-topdown.png`：Blender 预览。去桥后的模型已通过场景清单确认更新，未保留新的 GUI 截图。

源代码也已放到第二套工作区的 `usv_sim_full/worlds/models/gaogongdao_local_harbor_v1`，并新增 `worlds/ccs_open_water_gaogongdao_preview.sdf`。模型目录作为原项目资源路径的一部分可被搜索；加载完整预览世界时需先 source 原工作区的 install/setup.bash。
