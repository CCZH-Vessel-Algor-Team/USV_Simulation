# Changelog

后续修改本包功能、配置或文档时，应在 `Unreleased` 中记录面向使用者的变更。

## Unreleased

### Added

- 新增功能包架构和数据流文档。
- CCS BT v2 的运行时 RViz 配置生成器，加载受管任务面板和 USV Test Goal 航点工具。
- 导航/暂停/继续/结束、HOLD 接续、靠离泊接口检查、仿真控制权与故障测试按钮及回归测试。

### Changed

- USV BT v2 增加常驻同级 NAVIGATION/HOLD/DOCK/UNDOCK 模式按钮；NAVIGATION 接续原导航检查点，新路线仍由航点页显式创建。
- HOLD 到达内半径后退出当前返航并持续监测，可反复越界返航；清理本轮计时与局部结果，不清锚点或累计重试预算。
- 更新 README，说明构建、配置和启动入口。
- CCS → 三视觉/毫米波 → Nav2/推进桥完整透传 v2 和测试参数，CCS 默认启用 v2。
- CCS 态势报告默认改为 5 Hz；map/odom 与安全节点对齐受控命名空间，清理链覆盖旧 v2 进程。
- 原三视觉 RViz 面板、工具、视角和保存布局保留；增量附加 USV BT v2 页签，原 Navigation 2 的 G、多点与暂停/继续/取消接入受管接口。
- 受管面板改为五页紧凑布局并限制尺寸提示，保留原 dock；暂存任务接续移至模式页，避免请求期间焦点转移将常用按钮滚出视野。
- 独立近距保护改用持续发布的原始雷达扇区，避免“无回波=无消息”被判为观测失效。
- v2 launch 使用绝对船舶命名空间，修复 CCS 外层 PushRosNamespace 导致的 `/usv_1/usv_1` 叠加。
